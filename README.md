# Cromvena Studio — First Design Website

This website follows the first dark cinematic Cromvena Studio design:
- Real Estate-focused hero
- Portfolio categories
- Services
- About
- Client upload section
- Testimonials
- Contact form
- Floating WhatsApp / Email / Contact buttons
- Responsive layout
- Smooth scroll and reveal animations

## Before publishing
Replace `8801XXXXXXXXX` with your real WhatsApp/contact number.
Replace `hello@cromvenastudio.com` with your real email.

## Video uploads
The portfolio UI is ready for project cards. For a real public system where you can upload videos every day and clients can upload files, connect the site to a backend/cloud storage (for example Supabase Storage + Database + Auth). The current static package intentionally does not pretend that local browser uploads are public.
